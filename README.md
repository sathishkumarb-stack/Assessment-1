# Week 1 Assessment

## Files
- `task1_python_core_oop.py` — functions, OOP, exceptions, comprehensions, and loops.
- `task2_files_api_env.py` — CSV/JSON, REST API, environment variables, and error handling.
- `task3_numpy_pandas_charts.py` — NumPy, Pandas cleaning/joins, and four charts.
- `task4_git_notebook.py` — creates project folders, README, requirements, `.gitignore`, and notebook.

## Setup
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Run each task from this folder:
```bash
python task1_python_core_oop.py
python task2_files_api_env.py
python task3_numpy_pandas_charts.py
python task4_git_notebook.py
```

The Task 2 script creates `data/employees.csv` if it does not exist. Task 3 can also create it.
For Task 4, complete the branch/commit/Pull Request/merge and screenshot steps using your GitHub account.
